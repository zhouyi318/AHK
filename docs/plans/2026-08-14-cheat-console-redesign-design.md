# 游戏外挂风格侧栏控制台设计

**目标**

把当前偏“开发工具”的统一脚本编辑器，重构成更像市面成熟游戏外挂的侧栏控制台：状态一眼可见、入口稳定、编辑与运行分区明确，同时保留现有脚本编辑、流程调度、OCR/找图测试与挂机运行能力。

## 一、整体结构

界面改为三段式布局：

1. 左侧导航栏  
只保留一级导航，固定包含：
- 主页
- 脚本编辑
- 流程调度
- 挂机设置
- 运行日志

2. 中间主工作区  
当前页面的核心内容全部在这里显示。同一时间只呈现一个模块，避免脚本编辑、流程调度、测试工具同时堆在一页造成视觉混乱。

3. 右侧状态栏  
常驻显示运行态信息：
- 当前绑定窗口
- 当前流程 / 当前脚本 / 当前步骤
- 当前状态
- 热键
- 全局找图相似度
- 最近日志摘要

## 二、主页

主页是“驾驶舱”，不是编辑器。

推荐拆成四个卡片区：

1. 运行总控
- 开始挂机
- 紧急停止
- 状态灯：空闲 / 运行中 / 暂停 / 异常

2. 窗口绑定卡
- 窗口标题
- 进程名
- 句柄
- 分辨率
- 重新选取窗口

3. 当前任务卡
- 当前流程
- 当前脚本
- 当前节点 / 当前步骤
- 最近一次动作结果

4. 快捷工具卡
- 测试找图
- 测试 OCR
- 查看 OCR 文本
- 设置相似度

主页的作用是让用户打开程序后，不进入编辑模式也能立刻开挂、停挂、检查状态。

## 三、脚本编辑页

脚本编辑页采用三栏式：

1. 左栏：脚本列表
- 新建脚本
- 保存脚本
- 删除脚本

2. 中栏：步骤列表
- 显示序号、启用状态、类型、摘要
- 顶部操作条：
  - 新增点击
  - 新增等待
  - 新增找图
  - 新增图点
  - 新增 OCR
  - 新增分支
  - 录制点击
  - 录制按键

3. 右栏：步骤属性
- 基本信息：名称、启用
- 参数区：坐标、图片名、目标文本、区域、超时、相似度
- 成功后动作：下一步 / 跳转 / 结束
- 失败后动作：下一步 / 跳转 / 结束

`配置识别步骤` 不再当成独立杂项按钮漂浮在页面顶部，而是作为右栏属性区中的动作按钮存在，和当前选中步骤绑定。

## 四、流程调度页

流程调度页用于多个脚本串联、循环、失败回退。

同样采用三栏式：

1. 左栏：流程列表
- 新建流程
- 保存流程
- 删除流程

2. 中栏：节点列表
- 节点名
- 绑定脚本
- 成功后动作
- 失败后动作
- 循环方式

3. 右栏：节点属性
- 节点名称
- 绑定脚本
- 成功动作：下一节点 / 跳转 / 重复 / 停止
- 失败动作：下一节点 / 跳转 / 重复 / 停止
- 最大循环次数
- 是否入口节点

`运行当前流程` 只出现在流程调度页，不和单脚本运行按钮混放。

## 五、挂机设置页

挂机设置页承接所有全局参数，避免和编辑工作区混杂。

分三组：

1. 基础运行
- 启动/暂停热键
- 急停热键
- 主循环间隔
- 自动挂机重试次数
- 存仓间隔

2. 识别参数
- 全局找图相似度
- OCR 调试入口
- 系统图片区域管理

3. 异常处理
- 掉线处理图
- 死亡处理图
- 回城石兜底

## 六、运行日志页

日志页独立出来，不占主页主区域。

内容建议：
- 大号滚动日志框
- 仅显示最近若干百行
- 提供清空显示 / 刷新 / 复制日志

右侧状态栏仍保留最近 3 到 5 条摘要日志，用于常驻观察。

## 七、交互规则

1. 所有“运行”类动作都集中在主页、脚本编辑页、流程调度页，不重复堆满全局顶部。
2. 所有“配置”类动作都跟随当前对象显示，不再做大量全局按钮。
3. 所有测试工具都要明确区分：
- 全局测试：主页快捷工具
- 步骤配置测试：脚本编辑右栏

## 八、视觉风格

风格目标参考成熟外挂控制台，而不是 IDE：

- 深色背景
- 高对比按钮
- 当前导航高亮
- 状态颜色明确：
  - 绿色：运行中
  - 黄色：警告/等待
  - 红色：异常/停止
- 区块边界清楚，避免纯文字密集堆叠

不追求花哨，而追求“像外挂面板一样直观、压得住场”。

## 九、落地顺序

建议分三步实施：

1. 先改框架布局
- 左侧导航
- 中间工作区切页
- 右侧状态栏

2. 再改页面内容
- 主页
- 脚本编辑页
- 流程调度页
- 挂机设置页
- 日志页

3. 最后做视觉统一
- 深色风格
- 状态色
- 按钮尺寸
- 间距与分组边框

这样风险最小，也方便逐步回归验证。
